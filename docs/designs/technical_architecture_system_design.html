TIER 2 • CORE STREAM ENGINE

Complex Event Processing (CEP) Engine

com.odysseus.streaming.cep.AnomalyPatterns
Mecanismo & Lógica de Operación

Autómata Finito No Determinista (NFA) que evalúa en tiempo de evento dos estados consecutivos: Pico Térmico (T > 85°C) seguido por Anomalía Cinética (V_RMS > 4.5 mm/s) dentro de un umbral temporal de 30 segundos.

Garantía MLOps & Anti-Patrón Mitigado

Elimina falsos positivos aislados al exigir acoplamiento termomecánico en ventana temporal. Desacoplado asíncronamente hacia SQS para prevenir backpressure en TaskManagers.

Tier 01 • Ingest AWS Kinesis

Ingestion & Sharding

Generador multi-hilo en Python produce telemetría empaquetada mediante lotes KPL (PutRecords). La clave de partición vinculada a sensor_id garantiza orden cronológico estricto por activo.

  • Batched PutRecords (1 MB máx)
  • Jitter Temporal Realista (±2.5s)
  • Hash Slot Key Routing

Tier 02 • Core Flink Java 17

Stateful CEP Engine

Ejecución nativa sobre Flink con checkpoints incrementales RocksDB, ventanas deslizantes pre-agregadas en memoria, y autómata de estados finitos (NFA) para alertas compuestas.

  • withIdleness(30s) Guard
  • Ventana 1 min (slide 10s)
  • CEP: Spike ➔ Vibration (30s)
  • Side-Output DLQ para Malformed
Estado: RocksDB + Checkpoint (30s)
Tier 03 • Storage S3 + Athena

Zero-Crawler Analytics

El FileSink transaccional vuelca bloques Parquet (128 MB o 30 min) a S3. La **Partition Projection** de AWS Glue habilita consultas Athena instantáneas sin desfase de crawlers.

  • Rolling: 128 MB / 30 minutos
  • Exact-Once S3 Two-Phase Commit
  • Glue Partition Projection Activa
  • Abort Multipart Incomplete (1d)
Ruta: s3://.../telemetry/year=/...
Tier 04 • Alerts SQS ➔ Lambda ➔ SNS

Idempotent Notifications

Emisión no bloqueante hacia SQS FIFO que elimina backpressure en el stream. Lambda deduplica atómicamente mediante TTL de 15 min en DynamoDB antes de disparar SNS.

  • Token SHA-256 de Idempotencia
  • DynamoDB Conditional Put (15m)
  • BatchSize: 25 | Ventana: 5s
  • Cero Tormentas de Alertas en Replay
Buffer: odysseus-alerts.fifo

3. Formulación Matemática del Autómata de Estados CEP

Predicado A: Spike Térmico
T_t > 85.0 °C ∨ (ΔT / Δt) > 5.0 °C/sec
Detonado por fricción mecánica o falla en refrigeración.
Predicado B: Anomalía Cinética
V_RMS > 4.5 mm/s ∨ z-score > 3.0
Detonado por desbalance en eje de rotor o desgaste en rodamientos.
Restricción Temporal Compuesta
A followedBy B within(Time.seconds(30))
Emite token SHA-256 determinista a SQS FIFO.
